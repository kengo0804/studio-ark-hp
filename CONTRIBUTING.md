# Contributing

Thank you for considering contributing to this project!

## How to Contribute

1. Fork the repository
2. 2. Create a feature branch (`git checkout -b feature/your-feature`)
   3. 3. Commit your changes (`git commit -m 'Add your feature'`)
      4. 4. Push to the branch (`git push origin feature/your-feature`)
         5. 5. Open a Pull Request
           
            6. ## Code of Conduct
           
            7. Please read our [Code of Conduct](CODE_OF_CONDUCT.md) before contributing.
           
            8. ## Reporting Issues
           
            9. If you find a bug or have a feature request, please open an issue.
